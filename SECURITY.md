# Security policy

To report a vulnerability in a beliq-eu repository or a package published from one, or in the
beliq API, dashboard or website, write to the address named in
https://beliq.eu/.well-known/security.txt. Please do not open a public issue for it.

The [vulnerability disclosure policy](https://beliq.eu/legal/vulnerability-disclosure-policy/)
sets out what it covers, which testing is allowed and what we commit to in return. Its German
original, [Richtlinie zur Meldung von Schwachstellen](https://beliq.eu/de/legal/schwachstellen/),
is the binding version.

Fixes in published software are announced as a security advisory in the affected repository.
